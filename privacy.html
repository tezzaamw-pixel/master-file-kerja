Kebijakan Privasi — Master File Kerja

Terakhir diperbarui: 5 Oktober 2026

Data yang diakses

Aplikasi ini berjalan di dalam Google Sheets milik tim dan hanya membaca serta menulis spreadsheet dan file Google Drive yang memang dibuka atau dikelola oleh pengguna untuk keperluan kerja tim. Alamat email pengguna dipakai untuk mencatat siapa yang melakukan perubahan.

Penggunaan data

Data hanya dipakai untuk menjalankan fungsi aplikasi (mengolah data kerja di spreadsheet tim). Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dikirim ke server di luar layanan Google.

Penyimpanan

Semua data tetap tersimpan di Google Sheets / Google Drive milik pemilik spreadsheet. Aplikasi tidak menyimpan salinan data di tempat lain.

Pencabutan akses

Pengguna dapat mencabut izin aplikasi kapan saja melalui myaccount.google.com/permissions.
